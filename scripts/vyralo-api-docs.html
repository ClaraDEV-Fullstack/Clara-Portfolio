Laravel backend for the SMM growth platform — session-authenticated Inertia web routes, JSON payment webhooks, secured cron jobs, and SMM supplier panel integration via SmmApiService.

PostgreSQL PossaPay Crypto deposits SMM panel API Docker

SMM Supplier API (SmmApiService)

POSTsupplier panelaction: add
Place order — service, link, quantity → external order ID
POSTsupplier panelaction: status
Batch order status sync — charge, remains, completion state
POSTsupplier panelaction: services
Fetch supplier catalog for admin sync & service linking
POSTsupplier panelaction: balance
Supplier account balance check
POSTsupplier panelaction: refill
Request order refill from supplier panel
